# Source inventory: what to count

Public contract, 20 October 2026. No live personal-data inventory is published
here. A clone has code and invented fixtures, not a complete social graph.

| Source family | Unit to report | Important gap |
| --- | --- | --- |
| Archive profiles/posts | Eligible account IDs, authors, posts and dated package identity | Upload participation and source-use policy limit coverage |
| Historical shadow captures | Snapshots, profiles, distinct directed pairs and provenance | Capture centers and missing fields bias the observed network |
| Saved API evidence | Qualified profile/post/reference observations | A saved endpoint response is not a complete or current timeline |
| Cached websites | Pages, exact-account associations and claim sources | Linkage does not verify ownership or current availability |
| Saved work research | Sourced account/artifact associations | Association is not verified authorship or employment |
| Contact clues | Value/type/source/purpose/completion state | A clue is not a verified personal route or delivery |
| Curator tags | Curator/tag/account assignments, revisions, exclusions and unknowns | Examples are selected, overlapping and not representative ground truth |
| Derived graph/post index | Typed relations/entities, indexed authors/posts and release binding | Entity count is not person count; indexes inherit source gaps |

For each batch record the exact source, capture/publication time, eligible scope,
schema checks, admitted/rejected/unknown counts and reason, distinct IDs, duplicate
policy and before/after coverage. Do not infer full coverage from a successful import.

An old followed-account roster is not a verified current following list. A claimed
following total and stored outgoing edge count should both be visible. A blank
handle can coexist with a valid exact numeric ID; do not guess a handle or
silently discard that identity to satisfy a consumer.

Keep raw stores, tags and rollback copies intact. Derive a staged view, inspect
its Review evidence, and activate it only under the applicable authority. External
outages need not block independent, eligible local sources. See
[methods](guides/DISCOVERY_METHODS.md) and [data boundary](guides/DATA_BOUNDARY.md).
