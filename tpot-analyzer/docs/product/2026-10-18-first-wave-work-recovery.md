# Recover original saved public-work cards

## Decision

Use explicit repeatable work-source selection in the existing copied
saved-capture verification workflow. Require the exact already-retained profile
capture, numeric card ID and matching captured handle. Append only
`research_associates_with` observations, web resources and raw snapshots; do not
create profiles, identity claims or contacts.

Keep original byte-exact sources and pointers, unknown observation dates and
literal work dates. Retain card-level caveats with their own source pointer and
explicit `evidence_url` when it differs from the work URL. Do not treat a
homepage account of a project as inspected project-page text. Event fit, drafts,
outreach, availability, travel and willingness fields must not enter work
attributes or search ranking.

## Consumer and acceptance

Existing private Review search and work dossier show matching passages, source
URL/pointer and qualifications. When `evidence_url` differs from the work URL,
show a distinct safe inspected-source link. Reuse copied-source validation,
repeat/integrity/prior-row/adoption/rollback machinery. Reject false-ready or
no-new imports. Check source refusal/auth and a real before/after work search plus
account opening. Keep raw stores, tags, index/package and old graph intact. No
paid fetch, outreach, push or public deployment is implied.
